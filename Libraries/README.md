# Arduino Libraries

Install the following libraries before uploading the code to Arduino Uno.

## Required Libraries

- DHT Sensor Library
- Adafruit Unified Sensor
- MQ135 Library

## Installation

1. Open Arduino IDE.
2. Go to **Sketch → Include Library → Manage Libraries**.
3. Search and install:
   - DHT Sensor Library
   - Adafruit Unified Sensor
   - MQ135
