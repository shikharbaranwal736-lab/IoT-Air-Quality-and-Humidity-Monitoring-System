## Hardware Connections

| Component | Arduino Pin |
|-----------|-------------|
| MQ135 AO | A0 |
| MQ135 VCC | 5V |
| MQ135 GND | GND |
| DHT11 DATA | D7 |
| DHT11 VCC | 5V |
| DHT11 GND | GND |
| Buzzer + | D8 |
| Buzzer - | GND |
